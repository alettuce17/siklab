Cloud Controller Setup

Configure ESP Player

SikLab is hosted online using Netlify + Supabase. There is no laptop/server IP to enter. The ESP controller only needs an internet-connected Wi-Fi network or mobile hotspot.
1

Enter controller setup mode

Hold Button 5 + Joystick LEFT for about 3 seconds. The ESP restarts and creates SikLab-Setup-XXXXXX.

2

Connect to the ESP Wi-Fi

On your phone/tablet/laptop, join SikLab-Setup-XXXXXX. “No Internet” is normal while connected to the controller.

3

Open the controller

This button navigates directly to 192.168.4.1. The actual Wi-Fi password and device token are entered on the ESP-hosted page, not sent cross-origin by this Netlify page.

Both physical controllers can use 192.168.4.1 because each controller creates its own temporary Wi-Fi network. After saving, the ESP leaves setup mode, joins your internet Wi-Fi/hotspot, and communicates with Supabase Cloud.
